Keine E-Mail bekommen? Das liegt fast immer an Supabase, nicht an dir: Im Gratis-Tarif werden nur wenige Mails pro Stunde verschickt, viele landen im Spam – und wenn deine Adresse schon aus einem früheren Versuch existiert, wird gar keine neue Mail mehr geschickt.
  1. Supabase → Authentication → Providers → Email → „Confirm email" ausschalten
  2. Supabase → Authentication → Users → deinen Nutzer löschen (der alte, unbestätigte blockiert die Adresse)
  3. Hier in bazed neu registrieren → Login klappt sofort, ohne Mail
